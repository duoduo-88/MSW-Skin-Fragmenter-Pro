# MSW Skin Fragmenter Pro v1.3.1

## English

- Added a degraded-fragment workflow that can generate fragments directly from a degradation source image.
- Added subtle contour gaps and offset line artifacts for degraded fragments.
- Improved degradation preview, fragment-generation controls, progress reporting, and cancellation-state recovery.
- Improved PSD export and related bilingual interface text.

- 改善劣化預覽、碎片製作控制、進度顯示與取消後的狀態復原。
