# MSW Skin Fragmenter Pro v1.3.0

## English

Version 1.3.0 reorganizes the original single-file application into maintainable modules and delivers a packaged Windows build.

- Added the primary/secondary-mask fragmentation workflow.
- Integrated interference processing into full-image and local fragmentation.
- Added fragment selection, visibility, layered preview, recovery, and context-menu actions.
- Added PSD-template export with background processing and progress feedback.
- Added Traditional Chinese / English interface switching.
- Improved pixel-processing performance, task isolation, and completion-state handling.
- Added consistent hover and pressed feedback without changing the established layout.
- PSD template files are intentionally excluded from source control and release assets.

Fragmentation is an obfuscation measure and cannot guarantee that client-visible assets are unrecoverable.

## 繁體中文

v1.3.0 將原本的單檔程式重整為較容易維護的模組，並提供 Windows 打包版本。

- 新增主體／次要遮罩拆解流程。
- 完整拆解與局部分割均整合干擾像素處理。
- 新增碎片複選、顯示開關、疊圖預覽、復原與右鍵操作。
- 新增 PSD 範本匯出、背景處理與進度顯示。
- 新增繁體中文／英文介面切換。
- 改善像素處理效能、工作隔離與完成狀態管理。
- 在不改變既有版面的前提下，補齊按鈕游標懸停與按下效果。
- PSD 範本檔案刻意不納入原始碼與 Release 資產。

碎片化屬於混淆措施，無法保證用戶端可見的素材永遠無法被還原。
