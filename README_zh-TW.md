# MSW 造型防盜拆解工具 專業版

[English](README.md)

MSW Skin Fragmenter Pro 是 Windows 桌面圖片拆解工具，可將含透明度的 PNG 美術圖分割為可獨立管理的碎片。程式支援遮罩限制、重疊與干擾像素、局部分割、劣化處理、還原預覽，以及 PNG 或 ZIP 匯出。

目前發佈版本：**v1.2.0**

[下載 Windows 發佈包](https://github.com/duoduo-88/MSW-Skin-Fragmenter-Pro/releases/latest)

> 圖片拆解及干擾屬於混淆輔助措施，不是加密，無法保證美術圖絕對不能被還原。

## 主要功能

- 將透明 PNG 拆分為 1～10 張碎片，可調整方塊尺寸與尺寸隨機倍率。
- 支援同尺寸 PNG 遮罩、遮罩反轉，以及將碎片裁切至遮罩範圍。
- 可加入重疊像素並調整比例與聚合程度。
- 可只重新拆解選取的矩形區域，保留其他區域的既有結果。
- 支援碎片排序、重新命名、複製、合併、匯入、匯出及刪除。
- 垃圾桶最多保留 99 個可復原的已刪除碎片。
- 可依密度、透明度、重疊方式及半透明區域設定產生干擾像素圖。
- 可對匯入圖片套用區塊劣化、噪點、明暗及色偏變化。
- 匯出前可使用還原與重疊預覽檢查合成結果。
- 高負載操作會使用背景執行緒及多進程加速。
- 圖片在本機處理，程式不包含網路上傳功能。

## 系統需求

### Windows 發佈包

- Windows 10 或 11
- 可容納程式 1280 × 800 最小視窗的顯示環境
- 足以同時容納完整 RGBA 圖片與多張碎片的記憶體

發佈包已包含可執行檔，不必另外安裝 Python。

### Python 原始碼

- 建議使用 Python 3.10 或更新版本
- `requirements.txt` 所列套件：PySide6、NumPy、Pillow

安裝依賴：

```powershell
python -m pip install -r requirements.txt
```

執行目前版本：

```powershell
python "MSW Skin Fragmenter Pro v1.2.0.py"
```

Repository 亦保留 `MSW Skin Fragmenter Pro v1.1.7.py` 作為較舊的備用版本。

## 基本操作流程

1. 選擇含透明度的 PNG 主圖。
2. 視需要載入同尺寸 PNG 遮罩，並設定碎片是否可超出遮罩。
3. 設定拆分張數、方塊尺寸、隨機度、重疊比例及重疊聚合程度。
4. 點擊「執行拆解」。
5. 檢查、排序、重新命名或進一步管理產生的碎片。
6. 視需要產生干擾像素，或套用劣化處理。
7. 透過還原／重疊預覽檢查合成結果。
8. 將選取碎片匯出為 PNG，或將全部碎片匯出為 ZIP。

若要局部分割，先在預覽區按住右鍵拖曳選取範圍，再點擊「局部分割」。

## 輸入與輸出

- 主圖：建議使用含透明度的 PNG
- 選用遮罩：與主圖尺寸相同的 PNG
- 匯入碎片或劣化來源：程式檔案對話框及 Pillow 支援的圖片格式
- 碎片輸出：透明 PNG
- 批次輸出：包含 PNG 碎片的 ZIP

## 隱私

目前原始碼只會讀寫本機檔案，不包含圖片上傳或遙測用戶端。作業系統對話框及第三方執行元件仍適用各自的行為與政策。

## 限制

- 每次只處理一張主圖。
- 大尺寸圖片、高碎片數、很小的方塊及高密度干擾可能需要大量時間與記憶體。
- 背景運算尚未完成時關閉程式，未完成的操作可能被取消。
- 拆解效果取決於圖片內容及參數，任何設定都不能保證輸出無法還原。
- 本文件正式支援 Windows 發佈包；其他平台或許能執行 Python 原始碼，但本專案未加以驗證。
