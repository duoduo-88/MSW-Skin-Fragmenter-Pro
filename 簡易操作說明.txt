MSW 造型防盜拆解工具 專業版 v1.2.0
========================================

完整繁體中文說明請參閱：README_zh-TW.md
英文說明請參閱：README.md

Windows 發佈包：
https://github.com/duoduo-88/MSW-Skin-Fragmenter-Pro/releases/latest

執行 Python 原始碼：

1. 建議安裝 Python 3.10 或更新版本。
2. 在本資料夾執行：
   python -m pip install -r requirements.txt
3. 啟動目前版本：
   python "MSW Skin Fragmenter Pro v1.2.0.py"

基本流程：

1. 選擇含透明度的 PNG 主圖。
2. 視需要載入同尺寸 PNG 遮罩。
3. 設定拆分張數、方塊尺寸、隨機度與重疊參數。
4. 執行拆解並檢查碎片。
5. 視需要使用干擾像素、劣化處理或局部分割。
6. 透過還原／重疊預覽檢查結果。
7. 匯出 PNG 碎片或 ZIP。
